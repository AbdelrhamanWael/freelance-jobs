# 📊 منصة قواعد بيانات المانحين والشركات والمسؤولية المجتمعية (Freelance Suite)

مشروع احترافي متكامل مصمم خصيصاً لمشاريع العمل الحر (Freelance) لإعداد وتوريد قواعد بيانات موثقة ومعتمدة مع حزمة سكريبتات الكشط الآلي المتخصصة:

1. **قاعدة بيانات منطقة نجران (100 كيان مخصص)**:
   * **50 شركة ومقاولات في نجران** (منصات مقاول، اعتماد، الصفحات الصفراء نجران).
   * **30 جمعية أهلية ومانحاً في نجران** (المركز الوطني NCNP، منصة إحسان، وزارة الموارد).
   * **20 جهة مسؤولية مجتمعية في نجران** (أسمنت نجران، جامعة نجران، المستشفيات، البنوك، الغرفة التجارية).

2. **قاعدة البيانات الإقليمية الكبرى (100 كيان - السعودية، مصر، الإمارات)**:
   * **50 شركة كبرى** من أدلة الشركات (Yellow Pages، تداول، مباشر، زاوية).
   * **30 جهة مانحة ومؤسسة خيرية** (إحسان، Arab.org، المركز الوطني).
   * **20 جهة مسؤولية مجتمعية عالمية وإقليمية** (UN Global Compact، البنوك المركزية).

## 📑 هيكل وتفاصيل ملف الإكسيل (Excel Workbook Architecture)

تم بناء الملف المرفق بتصميم بصري احترافي (Executive Corporate Design) يدعم **الاتجاه من اليمين لليسار (RTL)**، وتنسيق الألوان المتناسق، وتحديد الأعراض تلقائياً، والروابط التفاعلية:

### 1. ورقة "نظرة عامة وإحصائيات" (Dashboard):
* **بطاقات أداء رئيسية (KPI Cards):** توضح إجمالي الجهات (100)، الشركات (50)، المانحين (30)، والمسؤولية المجتمعية (20).
* **جدول التوزيع الجغرافي:** (المملكة العربية السعودية: 44%، جمهورية مصر العربية: 37%، الإمارات العربية المتحدة: 19%).
* **سجل المنصات والمصادر المعتمدة:** توثيق مصادر البيانات وحالة التحقق من الأرقام والروابط.

### 2. ورقة "أدلة الشركات (50 شركة)":
* تشمل 50 شركة مساهمة وتجارية ومقاولات كبرى في السعودية ومصر والإمارات (مثل: الفنار، المقاولون العرب، ماجد الفطيم، السويدي إليكتريك، إعمار، المراعي، النهدي، عِلم، طلعت مصطفى...).
* **الحقول:** م | اسم الشركة | الدولة | المدينة | طبيعة النشاط والتصنيف | رقم التواصل المعتمد | البريد الإلكتروني | الموقع الإلكتروني | العنوان التفصيلي | المصدر المرجعي.

### 3. ورقة "الجهات المانحة (30 جهة)":
* تشمل 30 مؤسسة مانحة كبرى وجمعيات تنموية (مثل: مؤسسة الملك خالد، مؤسسة الوليد للإنسانية، مؤسسة مصر الخير، جمعية الأورمان، بنك الطعام المصري، مؤسسة سليمان الراجحي، مبادرات محمد بن راشد، مؤسسة ساويرس، مركز مجدي يعقوب للقلب...).
* **الحقول:** م | اسم المؤسسة المانحة | الدولة | المقر | نوع الكيان | مجالات المنح والدعم (تعليم، صحة، كفالة، تمكين) | الفئات المستهدفة | شروط ومعايير قبول الدعم | رقم التواصل | البريد الإلكتروني | رابط بوابة المنح | العنوان | المصدر.

### 4. ورقة "المسؤولية المجتمعية (20 جهة)":
* تشمل 20 جهة رائدة في الاستدامة والـ CSR (أرامكو السعودية، سابك، stc، CIB، بنك مصر، فودافون مصر، اتصالات e&، أدنوك، بنك أبوظبي الأول، البنك المركزي المصري والسعودي...).
* **الحقول:** م | اسم الكيان | الدولة | المقر | قطاع العمل | اسم برنامج الـ CSR | أبرز مبادرات الاستدامة | مجالات التركيز | رقم التواصل | بريد المسؤولية المجتمعية | الموقع الرسمي | المقر | المصدر.

### 5. ورقة "السجل الشامل (100 جهة)":
* سجل موحد جامع لكافة الكيانات الـ 100 مزود بخاصية التصفية التلقائية (Auto-Filter) لفرز البيانات بالدولة أو التصنيف أو طبيعة النشاط في شاشة واحدة.

## 🛠️ تحليل الكود النموذجي: لماذا تفشل السكريبتات المبتدئة على المواقع الحقيقية؟

في الكود التجريبي الشائع:
```python
response = requests.get(BASE_URL + str(page), headers=HEADERS)
soup = BeautifulSoup(response.text, 'html.parser')
companies = soup.find_all('div', class_='company-listing-card')
phone = comp.find('span', class_='phone-number').text.strip()
```

### التحديات الواقعية التي تم حلها في هذا المشروع:
1. **أرقام الهواتف المخفية (AJAX / Lazy Loading):**
   * في مواقع مثل **Yellow Pages**، لا يتم كتابة رقم الهاتف في كود الـ HTML الثابت بل يتم جلبه بطلب غير متزامن `GET /ar/getPhones/<id>/false` عند تفاعل المستخدم.
   * **الحل المنفذ:** تم برمجة دالة `fetch_phone_number()` في سكريبت `scraper_yellowpages.py` للاتصال المباشر بهذه النقطة وسحب الأرقام بنجاح.
2. **المواقع أحادية الصفحة (SPAs / Dynamic Rendering):**
   * مواقع مثل **منصة إحسان** و **Mubasher** و **Zawya** تعتمد على React و Next.js و Nuxt؛ وبالتالي لا يحتوي كود الـ HTML القادم من `requests` العادي على بيانات البطاقات.
   * **الحل المنفذ:** تم استخراج البيانات عبر نقاط الـ API المباشرة وتضمين البيانات المدققة مسبقاً في مولد قاعدة البيانات.
3. **جدران الحماية ومكافحة البوتات (Cloudflare & WAF):**
   * أدلة مثل `Arab.org` و `Zawya` تطبق Cloudflare Bot Management يمنع طلبات البايثون المباشرة التي لا تحمل رؤوس متصفح كاملة.
   * **الحل المنفذ:** إعداد رؤوس متصفح متقدمة (Realistic User-Agent + Accept-Language + Sec-Ch-Ua) مع فترات انتظار ذكية (Politeness Delays).

## 🚀 كيفية تشغيل وتعديل السكريبتات (Usage Guide)

### 1. إعادة توليد ملف الإكسيل الرئيسي (100 جهة):
```bash
python build_full_database.py
```

### 2. تشغيل كاشط الصفحات الصفراء (Yellow Pages):
```bash
python scrapers/scraper_yellowpages.py
```
* يمكنك تعديل كلمة البحث ونطاق الصفحات داخل السكريبت:
```python
scrape_yellowpages(keyword="مقاولات", max_pages=5, target_count=50, country="eg") # أو country="sa"
```

### 3. تشغيل كاشط الميثاق العالمي للأمم المتحدة (UN Global Compact):
```bash
python scrapers/scraper_ungc_csr.py
```

### 4. تشغيل كاشط الجهات المانحة (Arab.org):
```bash
python scrapers/scraper_donors_directory.py
```
