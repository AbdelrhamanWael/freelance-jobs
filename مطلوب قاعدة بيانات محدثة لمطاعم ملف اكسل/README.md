# 📊 نظام إنشاء قاعدة بيانات مطاعم الرياض والدرعية والخرج (.xlsx)

مشروع احترافي متكامل لسحب وتنقية وتصدير بيانات المطاعم في مدينة **الرياض** ومحافظتي **الدرعية** و**الخرج** إلى ملف إكسل احترافي جاهز للتسليم المباشر، متوافق بنسبة 100% مع شروط الجودة المطلوبة.

---

## 🌟 مميزات النظام والملف الناتج

1. **الامتثال التام لشروط العميل:**
   - خلو كامل من التكرارات (Deduplication) بناءً على معرف المكان ورقم الهاتف والموقع.
   - تنقية أرقام الهواتف السعودية وتوحيدها بالصيغة الدولية (`+9665XXXXXXXX` للجوالات و `+96611XXXXXXX` للهواتف الثابتة).
   - توليد رابط واتساب مباشر (`https://wa.me/966...`) يتيح للعميل مراسلة المطاعم مباشرة بنقرة زر واحدة.
   - التحقق الصارم من البريد الإلكتروني واستبعاد العناوين الوهمية والمؤقتة.
   - استخراج وتحديد الأحياء بدقة (العليا، الملقا، حطين، البجيري، العزيزية، إلخ).

2. **تصميم إكسل فاخر وتنظيم احترافي:**
   - دعم كامل للغة العربية والاتجاه من اليمين لليسار (**RTL**).
   - ترويسة أنيقة باللون الكحلي الداكن مع خط أبيض عريض.
   - تلوين سطري متبادل (Zebra Striping) لقراءة مريحة.
   - روابط تشعبية قابلة للنقر (Hyperlinks) لخرائط جوجل ومراسلة الواتساب والموقع الرسمي.
   - شيتات مقسمة تلقائياً:
     - `الملخص والإحصائيات`: لوحة تحكم بالأرقام ونسب توفر البيانات.
     - `جميع المطاعم`: قاعدة البيانات الموحدة مع فلاتر جاهزة للفرز والتصفية.
     - `الرياض`: مطاعم العاصمة وأحيائها.
     - `الدرعية`: مطاعم الدرعية ومطل البجيري.
     - `الخرج`: مطاعم محافظة الخرج.

## 🛠️ كيفية الإعداد والتشغيل السريع

### 1. إدخال رمز الوصول (Apify API Token)
افتح ملف `.env` وضع التوكن الخاص بك:
```env
APIFY_API_TOKEN=apify_api_XXXXXXXXXXXXXX
```

---

### 2. أوامر التشغيل المتاحة

#### أ) استخراج العينة الأولية (Sample Mode - 15 إلى 20 مطعماً)
> **تنبيه:** يوصى بهذا الوضع أولاً لتسليمه للعميل كعينة أولية معتمدة ولتوفير استهلاك رصيد Apify:
```bash
python scraper.py --mode sample
```
*يتم إنتاج الملف:* `sample_restaurants_riyadh.xlsx`

---

#### ب) استخراج قاعدة البيانات الكاملة (Full Mode - 500 إلى 1,000 مطعم)
> يُشغّل بعد اعتماد العينة من قِبل العميل لجمع التغطية الشاملة:
```bash
python scraper.py --mode full
```
*يتم إنتاج الملف:* `restaurants_database_riyadh_full.xlsx`

---

#### ج) تجربة الملف واستعراض التنسيق الفوري (Demo Mode)
> يتيح لك رؤية عينة حية وفورية لتنسيق الإكسل بدون استهلاك أي رصيد من Apify:
```bash
python scraper.py --demo-sample
```
