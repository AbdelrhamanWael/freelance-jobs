This repository acts as a centralized monorepo archiving production-ready source code, client deliverables, automation scripts, and datasets delivered for clients primarily across the GCC (Saudi Arabia, UAE) and international markets.

## 💻 Getting Started & Local Execution

### Prerequisites
- [Git](https://git-scm.com/) (with `core.longpaths true` enabled on Windows)
- [Git LFS](https://git-lfs.com/)
- [Python 3.10+](https://www.python.org/)
- [Node.js 18+](https://nodejs.org/)

### Clone Repository & Pull Large Files
```bash
# Clone the repository
git clone https://github.com/AbdelrhamanWael/freelance-jobs.git
cd freelance-jobs

# Pull all media and video assets managed by Git LFS
git lfs pull
```

### Running a Python Solution
Most Python projects include a `requirements.txt` and an execution script:
```bash
cd "Gulf Data Filter & Email Pinger"
python -m venv .venv
source .venv/bin/activate  # Or on Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### Running a Next.js / Frontend Solution
```bash
cd "Study Co/frontend"
npm install
npm run dev
```

## 📦 Git LFS & Media Handling

This repository utilizes **Git Large File Storage (Git LFS)** to manage high-definition video reels, media assets, and large binaries (`*.mp4`, `*.mov`, `*.avi`, `*.mkv`) without exceeding GitHub file size constraints.

To ensure all media files are downloaded on a fresh machine:
```bash
git lfs install
git lfs pull
```
